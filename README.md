# IT-Support Remote Ticket
These are the steps I followed to create a remote ticket on Spiceworks.
# Remote Support 
I logged into Spiceworks and navigated to the IT Tools then selected the "Remote Support" option on the drop down menu. 
# Start Remote Session
I got prompted to the "Start Remote Session" window by Zoho Assist.
# Session ID Invite 
Next window I was promted to share the Session ID number via email or copy the link and share it. I emailed the link to the client and instructed them to copy the link and paste it on the address bar. After that, client confirmed that they recived the email and followed my instructions and were prompted to download the Zoho Assist Agent so they can connect to the session. 
# Session Progress
A "Session Progress" screen popped up on my side showing that the client accessed the link and that the download was in progress. 
# Join Remote Support Session
After clicking the "Start Remote Session" blue tab the next screen was the the "Join Remote Support Session" window and I was required to enter a Session ID and my Name.
